An end-to-end customer analytics project focused on **customer behaviour, revenue performance, customer segmentation and retention-risk indicators** using Python, SQL and Power BI.

The project combines data cleaning, feature engineering, exploratory analysis, statistical testing, customer segmentation, relational SQL analysis and interactive business intelligence reporting.

---

## Project Overview

The objective of this project is to transform customer shopping data into actionable business insights.

The analysis investigates:

- Customer purchasing behaviour
- Revenue performance by category and season
- Subscription behaviour
- Purchase frequency
- Customer value segmentation
- High-value customers
- Retention-risk indicators
- Geographic performance
- Promotion and discount behaviour
- Statistical relationships between customer attributes and purchase value
